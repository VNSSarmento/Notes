## 📌 Sobre o Projeto

O **Notes App** é uma aplicação web completa (monolito) desenvolvida para facilitar a criação, organização e busca de anotações pessoais. O sistema permite que os usuários se cadastrem, façam login e gerenciem suas notas de forma intuitiva, podendo separá-las por categorias.

## 🛠️ Funcionalidades e Detalhes Técnicos

Este projeto foi construído utilizando o padrão arquitetural **MVC** (Model-View-Controller) e conta com as seguintes features:

* **Autenticação de Usuários:** Sistema de login seguro, tratamento de erros no formulário e controle de sessão.
* **CRUD Completo:** Criação, leitura, atualização e exclusão de anotações.
* **Filtros e Buscas:** Separação de anotações por categorias dinâmicas e barra de pesquisa.
* **Paginação:** Sistema de paginação customizada integrada ao banco de dados para otimizar o carregamento.
* **Interface Responsiva:** Uso de Modais e estilização completa utilizando o framework utilitário **Tailwind CSS** em conjunto com as views **Blade**.
